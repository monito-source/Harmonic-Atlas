# Assets de Prueba OMR

Coloca aquí archivos pequeños para validar el pipeline:

- `partitura.png`: imagen limpia exportada desde un editor de partituras.
- `partitura.jpg`: foto o escaneo bien alineado y de alto contraste.
- `partitura.pdf`: PDF exportado desde MuseScore, Finale, Sibelius u otro editor.

Para las primeras pruebas usa material simple: una página, pocos compases, pentagramas completos y sin inclinación. Evita imágenes borrosas, sombras fuertes, fotos oblicuas o capturas recortadas.

No se incluyen assets pesados en el repositorio.

Asset incluido:

- `twinkle-twinkle-sheet-music.png`: imagen pequeña de prueba tomada de Wikimedia Commons, archivo "Twinkle Twinkle Sheet Music.png", dominio público.
- `greensleeves-aeolian-sheet-music.png`: imagen de mayor resolución tomada de Wikimedia Commons, archivo "Greensleeves Aeolian mode version sheet music.png", dominio público.
