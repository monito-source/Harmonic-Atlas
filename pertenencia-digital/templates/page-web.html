Distinciones clave

Espacio, propiedad, operación y escala no son lo mismo

La navegación de Web separa lo que suele confundirse en una oferta digital: tener una carta de presentación, administrar un sitio propio, operar herramientas de negocio o integrar una operación completa.

Entrada accesible

Espacio digital compartido

Cuando el proyecto necesita una buena carta de presentación digital sin asumir todavía dominio, hosting e instalación propia.

  • Una página dentro de una estructura compartida.
  • Edición por bloques y plantillas básicas.
  • Costo distinto si el usuario edita o si yo personalizo todo.

Propiedad mínima

Presencia mínima propia

Cuando ya conviene tener dominio, hosting mensual y una instalación WordPress propia, pero la administración sigue siendo sencilla y accesible.

  • Nuevo, simple y sin complicaciones.
  • Importación desde el nivel compartido, temas, plantillas o sitio WordPress existente.
  • Base mensual clara, dominio anual y honorarios de migración cuando aplica.

Siguiente escala

Sitio profesional agrega herramientas y plugins de administración, tienda hasta 80 productos y consultorías de requisitación. Enterprise se reserva para operaciones consolidadas y suele cotizarse desde 60k MXN.
