# On Building Page

Plugin amigo de `pertenencia-digital` para marcar páginas públicas como:

- en construcción
- en mantenimiento
- fuera de servicio

## Qué hace

- Los administradores siguen viendo el contenido real.
- Los visitantes y usuarios no administradores ven un aviso claro en lugar del contenido de la página.
- La navegación del sitio se conserva porque el plugin reemplaza solo el contenido del `<main>`.

## Dónde se configura

- `Ajustes > On Building Page`
- metabox `On Building Page` dentro del editor de cada página

## Campos por página

- estado público
- eyebrow público opcional
- título público opcional
- mensaje público opcional

## Carpeta

`on-building-page/`
