# Pertenencia Digital Tickets

Plugin WordPress para gestionar tickets, solicitudes de servicio y productos contratables del área Tecnologías y Web.

## Alcance inicial

- CPT `pd_ticket` para solicitudes privadas.
- CPT `pd_service_product` para servicios/productos contratables.
- Taxonomía `pd_ticket_area` para separar Web, Tecnologías digitales y Multimedia.
- Shortcode `[pd_technology_ticket_form]` para crear tickets desde páginas públicas.
- Shortcode `[pd_technology_ticket_portal]` para explicar el flujo de atención.
- Shortcode `[pd_technology_services]` para listar servicios contratables.

## Intención

Este plugin separa la funcionalidad de captación y seguimiento del tema FSE. El tema presenta el modelo editorial; el plugin guarda solicitudes y puede crecer hacia CRM ligero, estados, respuestas, panel de cliente o pagos.
